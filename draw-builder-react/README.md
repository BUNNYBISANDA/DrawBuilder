# draw-builder-react

The Galle Zonal Draw Builder app (React + Vite + Supabase).

See the [repo root README](../README.md) for full documentation — features,
architecture, real-time sync/offline behavior, Supabase setup, and
deployment.

## Quick start

```bash
npm install
cp .env.example .env.local   # fill in your Supabase project URL + anon key
npm run dev
```

```bash
npm run build      # production build -> dist/
npm run preview    # preview the production build
npm run lint        # oxlint
```
